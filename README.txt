Hochladen:
Alle 5 Dateien gemeinsam in das Stammverzeichnis eines HTTPS-Webhosts hochladen.
Geeignet ist z.B. GitHub Pages.

Danach auf dem iPhone:
1. Die HTTPS-Adresse in Safari öffnen.
2. Teilen > Zu Home-Bildschirm hinzufügen.
3. Falls angeboten: Als Web-App öffnen aktivieren.
4. Hinzufügen.

Wichtig:
Die Vokabeln und Lernstatistik werden lokal im Browser gespeichert.
Die Foto-Texterkennung lädt Tesseract.js beim Gebrauch über das Internet.
Deshalb funktioniert der Lernteil offline, die erstmalige/erneute OCR-Nutzung kann Internet benötigen.
